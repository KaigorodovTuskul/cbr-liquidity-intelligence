# Contributing to CBR Liquidity Intelligence

Contributions are welcome! Please follow these guidelines:

1. **Keep it Lean:** No heavy ORMs, databases, or unnecessary wrappers.
2. **Preserve Methodology:** Ensure that financial terminology adheres to Bank of Russia standards (Stock vs Flow, H2/H3 ratios, account classifications).
3. **Validate:** Run `python scripts/validate.py` before opening pull requests to ensure spec compliance.
