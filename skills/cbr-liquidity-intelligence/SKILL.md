# CBR Liquidity Intelligence — Анализ ликвидности банков РФ

**Автономный навык для сбора, обработки и анализа ликвидности банковской системы России** на базе первичной отчетности Банка России (ЦБ РФ) за 2024–2026 гг.

## Назначение и источники данных

Скилл предоставляет воспроизводимый пайплайн извлечения открытых данных без внешних платных API и тяжелых СУБД:

| Код | Показатель | Тип | Первоисточник ЦБ РФ | Смысловое значение |
|---|---|---|---|---|
| **S1** | Депозиты банков в ЦБ | Stock (остаток) | `cbr.ru/hd_base/ostat_depo_new/` | Абсорбирование свободной ликвидности ЦБ |
| **S2** | Обороты МБК и РЕПО | Flow (дневной оборот) | `cbr.ru/statistics/finr` | Активность денежного рынка (все сроки и овернайт) |
| **S3** | Ставка и объем RUONIA | Flow (дневной оборот) | `cbr.ru/hd_base/ruonia/dynamics/` | Индикативная ставка овернайт МБК выборки банков |
| **S4** | Аукционы РЕПО ЦБ РФ | Flow (сделки) | `cbr.ru/hd_base/repo/` | Предоставление (кредитование) ликвидности регулятором |
| **S7** | Форма 101 (Оборотная ведомость) | Stock (остатки) | `cbr.ru/banking_sector/otchetnost-kreditnykh-organizaciy/` | Счета 319 (ЦБ), 32.1 (МБК разм.), 31.1 (МБК привл.), 301 |
| **F135** | Форма 135 (Обязательные нормативы) | Ratio (нормативы) | `cbr.ru/banking_sector/otchetnost-kreditnykh-organizaciy/` | Нормативы мгновенной (Н2) и текущей (Н3) ликвидности |
| **F123** | Форма 123 (Собственные средства) | Stock (капитал) | `cbr.ru/banking_sector/otchetnost-kreditnykh-organizaciy/` | Капитал банка (код 000) для расчета левереджа |

## Базовые правила методологии (НЕ НАРУШАТЬ)

1. **Stock ≠ Flow:** Никогда не суммируйте остатки (счет 319, Форма 101, S1) со среднедневными оборотами (S2, S3). Это грубая экономическая ошибка.
2. **РЕПО ЦБ — это кредит регулятора:** Операции РЕПО Банка России (S4) представляют собой *предоставление ликвидности* банкам под залог ценных бумаг, а не размещение средств банками.
3. **RUONIA — репрезентативная выборка:** Объем сделок RUONIA охватывает сделки только ~20–30 утвержденных банков, а не весь рынок МБК.
4. **Агрегат счета 32.1:** С 2024–2026 гг. в публичной Форме 101 ЦБ РФ счета 320 и 321 кодируются единой строкой `"32.1"`. Выделение нерезидентов из публичных DBF регуляторно закрыто.
5. **Надзорная конфиденциальность:** Формы 0409501 (сделки МБК) и 0409701 (сделки денежного рынка) закрыты банковской тайной. Анализ по банкам возможен только по Формам 101, 135 и 123.

## Запуск готовых скриптов

Все скрипты оптимизированы для прямого потокового разбора архивов ЦБ:

```bash
# 1. Собрать многолетнюю статистику по банкам за 2024-2026 гг. (Формы 101, 135, 123)
python scripts/fetch_multiyear_liquidity.py

# 2. Собрать оперативные макро-сводки (S1, S2, S3, S4)
python scripts/fetch_cbr_liquidity.py

# 3. Сгенерировать интерактивный HTML-дашборд и сводные таблицы
python scripts/build_visual_dashboard.py
```
