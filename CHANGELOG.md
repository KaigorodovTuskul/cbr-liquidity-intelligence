# Changelog

All notable changes to `cbr-liquidity-intelligence` will be documented in this file.

## [1.0.0] - 2026-10-30

### Added
- Standardized open-spec Agent Skill structure in `skills/cbr-liquidity-intelligence/`.
- Multi-year bank balance extractor for Forms 101, 135 (ratios H2, H3, H4) and 123 (capital) across 2024–2026.
- Direct high-performance streaming DBF reader without heavy database requirements.
- Full macro time series collector for CBR Deposits (S1), REPO/MBK daily turnover (S2), RUONIA (S3), and CBR REPO auctions (S4).
- Interactive static HTML dashboard generator with Chart.js charts and instant bank registry search.
- Zero-dependency multi-agent installer script `scripts/install.py`.
- Methodology guides on Russian money market liquidity, donor/recipient classification, and supervisory reporting boundaries.
